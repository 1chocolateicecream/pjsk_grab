# pjsk_grab — удобненько сохраняем сливы секая

качает свежие ивенты целиком (последние пару-тройку, чтоб точно не проспать дроп):
**истории, обложки, афтерлайв и карты ивента**, + **свежие карты вне ивента**
(дни рождения, коллабы) + **спец-истории**. текст — в `.txt` как «Имя: реплика»,
картинки — `.png`. уже скачанное не трогается, так что лишнего не натащит

## как пользоваться

- **мак:** двойной клик по `run_mac.command`
- **винда:** двойной клик по `run_windows.bat`
- **или ручками:** `python pjsk_grab.py`, либо же `python3 pjsk_grab.py` на маке

сам найдёт последний ивент, докачает то, чего ещё нет, и покажет отчётик:

```
═══ ивент 206 · 最果てへと飛ぶキミへ
    когда: 31.05.2026 – 08.06.2026
    истории   ✓✓✓✓✓✓✓✓   8/8 на серваке   ← свежак: 01, 02
    обложки   ✓ логотип   ✓ баннер
    афтерлайв ✓
    карты (5):
       res017_no051 · 形にした先で   истории ✓✓   картинки ✓ ✓
```

значки: **✓** — есть на серваке, **·** — ещё не завезли (появится позже)

## следить за сваком в фоне (мак) 🔔

не хочешь дёргать команду вручную перед сливами? запусти слежку — она сама проверяет сервак
и, как только завезут свежак, **качает его и пингует уведомлением со звуком**:

```
python3 pjsk_grab.py watch          # проверять каждую минуту (по умолчанию)
python3 pjsk_grab.py watch 5        # каждые 5 мин (число — это минуты)
python3 pjsk_grab.py --units watch  # для ворлд линка — сразу с юнитами
```

**первый проход — тихая синхронизация:** то, что уже на серваке (старые ивенты), подтянется
БЕЗ уведомления — это не свежак. пинг прилетит только про то, что завезут ПОСЛЕ старта

уведомление = **звук + баннер + подпрыг иконки в доке**. звук проигрывается
напрямую, так что услышишь даже если баннеры запрещены или включён режим «не беспокоить»
если хочешь ещё и баннер — разреши уведомления своему терминалу в Системных настройках →
Уведомления; а подпрыг иконки — это «звоночек» терминала (в его настройках включи bounce on bell)

запусти вечером перед сливами и забудь, окно можно свернуть. `Ctrl-C` чтоб остановить.
чтоб мак не уснул и не поставил слежку на паузу:
```
caffeinate -i python3 pjsk_grab.py watch
```

## официальный CDN и обход блокировок (Sega JP CDN) 🔄

скрипт умеет скачивать свежие сливы **напрямую с официального CDN серверов игры (JP)** и расшифровывать их на лету.

это происходит полностью автоматически:
- если зеркало `storage.sekai.best` ещё не успело обновиться (выдает 404), скрипт сам перенаправит запрос на Sega CDN, найдет нужный бандл в индексе, загрузит его и вытащит сценарий или картинку
- для этого под капотом используется библиотека `sssekai` и `UnityPy`. если библиотеки не установлены на компьютере, скрипт продолжит работу через зеркало в обычном режиме, не падая при запуске

## куда всё падает

рядом со скриптом появляется папка `PJSK/`:

```
PJSK/
  Ивенты/206 - .../              ← ивент целиком (истории, обложки, афтерлайв, карты)
  Карты/Дни рождения/...         ← др-карты вне ивента
  Карты/Коллабы и прочее/...     ← коллабные и прочие карты вне ивента
  Спец-истории/...               ← спецухи, если выходят рядом с ивентом
  Свежее 2026-06-03/             ← только то, что скачалось сегодня
```

**память == эта папка.** файл уже лежит в `PJSK/` → скрипт его не трогает
хочется перекачать заново? просто удали файл (или папку) и запусти снова

## проверить, что всё цело

```
python pjsk_grab.py check
```
делает три вещи:
1. ищет пустые/битые файлы (вдруг что-то скачалось криво);
2. сверяет архив с серваком: «всё, что сейчас на серваке, у тебя есть»;
   если чего-то не хватает — покажет, что именно (запусти обычный прогон, чтоб до-качать);
3. даёт ссылки на секай бест, если хочется сверить главы глазами

## что в текстах кроме реплик

в `.txt` сохраняются не только реплики «Имя: текст», но и:

- `［カフェ］` — подписи локаций и тайм-скипы (в т.ч. английские, типа `［WORLD LINK］`);
- `〈…текст…〉` — закадровый монолог (полноэкранный, без рамки);
- `【выбор】 『вариант1』 / 『вариант2』` — варианты выбора (бывают в спец-историях);
- `【флешбэк ↓】 … 【конец флешбэка ↑】` — флешбек, если внутри есть текст

**имена говорящих** переводятся на русский (все 26) — но только когда это ровно имя персонажа
`一歌の声` и `？？？` остаются как есть. имена правятся в начале `pjsk_grab.py` (словарь `CHAR_RU`)
нужны японские имена как в игре? добавь `--jp`

**юниты вокалойдов** по умолчанию НЕ приписываются — в обычном ивенте и так понятно, что воки того
же юнита, и `WxS Мику` был бы лишним шумом. а вот в ворлд линке / микс-ивентах, где воки
из разных юнитов вперемешку, добавь `--units`:
```
python pjsk_grab.py --units
```
тогда будет `L/n Рин`, `MMJ Лен`, `VBS Мику`, `N25 Мику`, а оригинал просто `Мику` (без префикса)

**подряд идущие реплики одного говорящего** склеиваются — имя пишется один раз:
```
Мику: うん。わたしは、セカイの外側——…
ただ……本当に見守ることしかできないから
わたしがみんなのセカイに行っても、…
```

## первый запуск на винде

1. поставить питон с <https://www.python.org/downloads/> —
   **обязательно** галочку «Add Python to PATH», а то не заведётся
2. скачать эту папку (со скриптом) к себе
3. двойной клик по `run_windows.bat`

если консоль ругается на сертификаты — `pip install certifi` (без него тоже работает,
но так аккуратнее)

## достать что-то конкретное (не из последнего дропа) с примерами

```
python pjsk_grab.py event 205         # ивент по id
python pjsk_grab.py event 205 full    # скачать только истории ивента одной книгой (все главы в одном файле)
python pjsk_grab.py event 205 solo    # скачать ивент (истории, обложки, афтерлайв) без карточек
python pjsk_grab.py episode 205 3      # ОДНА глава ивента (id ивента + номер главы), и ничего больше
python pjsk_grab.py card 1403          # карта по id
python pjsk_grab.py afterlive 472      # афтерлайв по id virtual live
python pjsk_grab.py special 3          # спец-история по id (там бывают выборы!)
python pjsk_grab.py list events 衣装   # найти id (events / cards / afterlives / specials)
```
